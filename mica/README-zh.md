# SumatraPDF Mica 预览版

这是基于官方最新源码制作的非官方便携版。解压后运行同目录下的 SumatraPDF.exe，无需安装开发工具。

- Windows 11 22H2 及以上：原生标题栏启用云母，标签显示在标题栏下方。
- 标签栏和工具栏采用调整后的浅色、深色配色，默认跟随系统主题。
- 文档页面保留原始颜色。云母仅用于标题栏，工具栏、侧栏和页面外围仍为实色。
- 高对比度、全屏和演示模式关闭云母。不支持云母的系统使用普通标题栏；系统关闭透明效果时也可能显示实色。
- 设置 → 高级选项，将 UseMica 改为 false 后重启，可恢复原来的标题栏布局。
- 此便携包关闭官方自动更新，避免定制版本被原版替换。

建议保留独立文件夹中的设置文件。不要覆盖现有安装目录。

源码：https://github.com/Guany725/sumatrapdf/tree/mica-modern-ui

准确版本记录在 SOURCE-COMMIT.txt；同次编译提供匹配的源码压缩包。许可和作者信息见 COPYING、COPYING.BSD 和 AUTHORS。
